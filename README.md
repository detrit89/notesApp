# Notes CLI App

Simple command line notes application built with Node.js.

## Features
- Add notes
- List notes
- Search notes
- Delete notes
- Save notes to JSON file

## Installation
Clone repository:
git clone <your-repo-url>
Go to folder:
cd cli

## Usage
Add note:
node index.js add "Buy milk"

Show all notes:
node index.js list

Search note:
node index.js search "milk"

Delete note:
node index.js delete 1

Help:
node index.js help

## Technologies
- JavaScript
- Node.js
- fs module

## Storage

Notes are stored in notes.json
